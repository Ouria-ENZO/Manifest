# MANIFEST — Independent Fan-Made Website Concept

A responsive editorial-style website concept celebrating Manifest, the six-member Turkish girl group.

> This is an independent, unofficial fan-made design concept. It is not affiliated with, endorsed by, or commissioned by Manifest, its members, label, or management.

## Preview locally

1. Download and extract the project.
2. Open `index.html` in a modern browser.
3. For the best local development experience, use the VS Code Live Server extension.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and folders from this project (keep the `assets` folder structure intact).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Project structure

- `index.html` — page structure and content
- `style.css` — responsive visual design and animations
- `script.js` — mobile navigation and scroll reveal interactions
- `assets/` — original SVG artwork created for this concept

## Photography and trademarks
